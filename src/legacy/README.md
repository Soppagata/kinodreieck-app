# Legacy-Browser-Sync

Die beiden Einstellungsoberflächen in diesem Ordner gehören zum alten
Browser-Secret-Sync. Sie sind nicht Teil des aktiven UI-Modulgraphen und kein
Accountmodell.

Sie bleiben vorläufig als Migrationsreferenz erhalten. Eine erneute Einbindung in
die Online-App ist ausgeschlossen; Account-Sync wird später ausschließlich über
die `auth`- und `storage`-Grenzen umgesetzt.
